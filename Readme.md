# Walmart Sales Analysis

## Project Overview

This project analyzes Walmart sales data using MySQL and Power BI to discover business insights and build an interactive dashboard.

## Tools Used

- MySQL
- SQL
- Power BI
- GitHub

## Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Quantity Sold
- Sales by Category
- Profit by Category
- Sales by Country
- Monthly Sales Trend
- Customer Analysis
- Product Analysis

## Key Insights

- Technology generated the highest sales.
- The United States had the highest overall sales.
- Sales peaked during specific periods, indicating seasonal demand.
- A small group of customers contributed significantly to total revenue.
